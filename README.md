# AI Security Gateway

A security gateway for controlling and auditing AI agent access to protected resources.

## Overview

AI Security Gateway explores how traditional security concepts can be applied to AI-powered systems.

The goal is to control what users and AI agents are allowed to access through authentication, authorization policies and audit logging.

## Features

- JWT Authentication
- Role-based authorization
- Policy-based access control
- AI agent authorization
- Audit logging
